## About

A cinematic, typography-driven canvas animation presenting 100 thoughtful statements about someone.

## Features

- 100 thoughtful statements
- Animated typography and glowing highlights
- Floating particles and light trails
- Automatic statement progression
- Pause, resume and restart controls
- Responsive layout

## Run Locally

No dependencies or installation required.

1. Clone or download the repository.
2. Keep all three files in the same folder.
3. Open `index.html` in your browser.

Alternatively:

```bash
python -m http.server 8000
```

Open http://localhost:8000.

## Controls

- **Pause:** Pause or resume the animation.
- **Restart:** Replay from the beginning.

## Customization

Edit the `statements` array in `100-things-about-you.js` to customize the messages.

Use asterisks around words to highlight them:

```js
"You make *ordinary moments* feel important."
```
